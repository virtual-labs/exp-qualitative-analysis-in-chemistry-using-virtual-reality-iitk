<h2>Actual vs Virtual Reality Lab Procedure</h2>

<h3 style="text-decoration:none;">1. Preparation & Safety :</h3>

<b>Actual (Physical Flame Test)</b><br>
Wear safety goggles and a lab coat. Ensure the work area is clean. Obtain the wire loop and the beaker of concentrated HCl.<br><br>

<b>Virtual Reality (VR) Lab Procedure</b><br>
The user enters the virtual lab. The system enforces a virtual safety check (e.g., requiring the user to wear virtual goggles with a click).

<hr>

<h3 style="text-decoration:none;">2. Cleaning the Loop :</h3>

<b>Actual (Physical Flame Test)</b><br>
Dip the wire loop into the concentrated HCl to clean it, then place it in the hottest part of the Bunsen flame until no color is visible (clean).<br><br>

<b>Virtual Reality (VR) Lab Procedure</b><br>
The user uses the VR Controller to grab the virtual wire loop and place it into the virtual cleaning solution. The system provides visual confirmation (e.g., a sparkle effect) that the loop is clean.

<hr>

<h3 style="text-decoration:none;">3. Sample Acquisition :</h3>

<b>Actual (Physical Flame Test)</b><br>
Dip the now-clean wire loop into the unknown metal salt sample to pick up a small amount of the substance.<br><br>

<b>Virtual Reality (VR) Lab Procedure</b><br>
The user grabs a virtual cube (representing the metal salt, as seen in the video) or a virtual reagent container. The system ensures the correct amount adheres to the virtual loop.

<hr>

<h3 style="text-decoration:none;">4. Heating and Observation :</h3>

<b>Actual (Physical Flame Test)</b><br>
Place the loop (with the salt) into the Bunsen burner flame and observe the color emitted. This color often flashes briefly.<br><br>

<b>Virtual Reality (VR) Lab Procedure</b><br>
The user places the virtual loop/cube into the virtual flame. The flame instantly changes color (e.g., bright orange/red, as suggested by the changing flame color in the video, 0:34).

<hr>

<h3 style="text-decoration:none;">5. Repeat & Identification :</h3>

<b>Actual (Physical Flame Test)</b><br>
Repeat the cleaning and testing process multiple times to ensure the result is consistent. Compare the observed color to a chart of known metal ion colors.<br><br>

<b>Virtual Reality (VR) Lab Procedure</b><br>
The VR system allows instant repetition (Step 2–4). It can then overlay a color reference chart or highlight the corresponding known metal ion (e.g., Sodium = Yellow/Orange).
